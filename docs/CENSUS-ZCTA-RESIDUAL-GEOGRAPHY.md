# Census ZCTA residual geography

The immutable dataset is `us-census-non-zcta-state-residual@1.0.0`: the geometric difference between each retained Census state-equivalent polygon and selected 2020 Census ZCTA polygons clipped to that state. The retained source has 56 state equivalents; the application's national state view covers the 50 states plus D.C.

An earlier proposed partition used projected N, E, S, W, and C sectors. The implemented application uses nine direction references on existing polygon components instead of splitting the geometry. These are orientation aids, not official regions. The residual includes water.

The layer is non-postal Census residual geometry. It never asserts ZIP membership, USPS operation, parks, Native or tribal land, private land, habitation, population, business location, business gaps, or ZIP completion. It contains no business geometry and does not block the existing state or ZCTA map.

The original `polygon-clipping` feasibility probe failed: D.C. and Rhode Island encountered ring-construction errors and California exceeded the measured time/memory budget. The subsequently installed GEOS capability resolved the residual-generation prerequisite described below. That historical probe is not a blocker for current state/industry rendering or the implemented component references. No production map overlay is enrolled.

The successor capability embeds `geos-wasm` 3.1.1, backed by GEOS 3.13.0, and uses validity repair, a fixed `1e-7` degree precision grid, polygonal extraction, fixed-precision union/intersection/difference, and per-state candidate filtering. Release `us-census-non-zcta-state-residual-af772d3aa8d9f7a0266a0aa5e507d6ebf8bd4998` contains one immutable GeoJSON artifact for every one of the 56 retained Census state equivalents. Its verifier reopens every artifact and independently recomputes all 56 differences from the exact retained Census release; exact replay passed. This is a national Census residual-geometry release, but not an area measurement, cardinal partition, ZIP/postal layer, park classification, tribal/Native classification, private-land classification, population statement, business geography, industry denominator, or production map enrollment.

The pointer-free, local-review-only readiness release `us-census-non-zcta-state-residual-readiness@1.0.0` materially narrows the remaining work without fabricating geometry. Its builder reads only the governed Census geography pointer and manifest, independently hashes the state index, ZCTA index and state geometry, checks all ten ZCTA geometry-partition declarations, proves 56/56 state-equivalent and 33,791/33,791 ZCTA inventory conservation, and publishes zero residual polygon features and null residual area. Its verifier reopens the current governed inputs and fails on byte drift, declaration drift, semantic tampering, unexpected release entries, symlinks or hardlinks. It performs no network request, writes no current pointer, and is not enrolled in production.

`runner/census-zcta-residual-geography.mjs` verifies the registered immutable national release and its selected state summary on every read. Residual-layer failure cannot suppress or alter the existing state/ZCTA map.

October 7 application orientation references: selecting a state now exposes uniquely labeled polygon components from its retained residual artifact. `component-bounds-midpoint-state-bounds-thirds@1.0.0` places each component's bounding-box midpoint within three longitude bands and three latitude bands of the retained state bounds. This yields northwest, north, northeast, west, central, east, southwest, south and southeast reference labels. Longitude is unwrapped by cutting at the largest gap in the state's longitude coordinates, so Alaska's antimeridian-crossing geometry is handled in one reference frame. Coordinates in this frame can exceed 180 degrees; the UI explicitly labels these as reference bounds.

This is an orientation rule over already retained components, not a new geographic subdivision, centroid, area measurement or topology operation. A component spanning several bands keeps one reference label. Its immutable ID combines the state abbreviation and full SHA-256 of its source polygon coordinates; the readable label includes state name, direction and a shortened digest. Labels can change when source geometry changes and do not assign non-ZCTA ZIPs or businesses to a component. Parks, Native/tribal territory, private land, population and business status remain unresolved because no governed classification overlay is currently retained.

The existing residual API accepts `state`, optional `direction` (all or one of the nine labels) and optional nonnegative `offset`. Each response conserves all component counts while returning at most 100 component references. Direction filtering and next/previous controls let the operator inspect every retained component without a large unbounded response. Repeated, extra or malformed options are rejected. The application binds results to state, direction, offset, release hashes, component count conservation and conservative claims; a stale, unavailable or incompatible context remains nonblocking. No source acquisition, current-pointer update or production enrollment is performed.

# Census ZCTA residual geography

The proposed immutable dataset is `us-census-non-zcta-state-residual@1.0.0`: the geometric difference between each retained Census state-equivalent polygon and selected 2020 Census ZCTA polygons clipped to that state. A future application view would default to the 50 states plus D.C.; the retained source has 56 state equivalents.

The intended partition uses projected, exhaustive N, E, S, W, and C sectors, with at most five features per state. These are orientation aids, not official regions. The residual includes water.

The layer is non-postal Census residual geometry. It never asserts ZIP membership, USPS operation, parks, Native or tribal land, private land, habitation, population, business location, business gaps, or ZIP completion. It contains no business geometry and does not block the existing state or ZCTA map.

No production release or map overlay is published. A retained-data feasibility probe failed closed: D.C. failed in 713 ms and Rhode Island in 1.075 s with polygon-clipping ring-construction errors; California exceeded 90 seconds, while a sector-first California probe exceeded 27 seconds and 2.8 GB for only 256 candidates. Alaska antimeridian and Hawaii multipart extents also require robust handling. Production requires a GEOS-class tiled overlay with geometry validity repair and a precision grid, plus state-partitioned immutable artifacts and replay verification. The installed dependency set does not provide that deterministic capability; `polygon-clipping` is not treated as a substitute after these measured failures.

The successor capability embeds `geos-wasm` 3.1.1, backed by GEOS 3.13.0, and uses validity repair, a fixed `1e-7` degree precision grid, polygonal extraction, fixed-precision union/intersection/difference, and per-state candidate filtering. Release `us-census-non-zcta-state-residual-af772d3aa8d9f7a0266a0aa5e507d6ebf8bd4998` contains one immutable GeoJSON artifact for every one of the 56 retained Census state equivalents. Its verifier reopens every artifact and independently recomputes all 56 differences from the exact retained Census release; exact replay passed. This is a national Census residual-geometry release, but not an area measurement, cardinal partition, ZIP/postal layer, park classification, tribal/Native classification, private-land classification, population statement, business geography, industry denominator, or production map enrollment.

The pointer-free, local-review-only readiness release `us-census-non-zcta-state-residual-readiness@1.0.0` materially narrows the remaining work without fabricating geometry. Its builder reads only the governed Census geography pointer and manifest, independently hashes the state index, ZCTA index and state geometry, checks all ten ZCTA geometry-partition declarations, proves 56/56 state-equivalent and 33,791/33,791 ZCTA inventory conservation, and publishes zero residual polygon features and null residual area. Its verifier reopens the current governed inputs and fails on byte drift, declaration drift, semantic tampering, unexpected release entries, symlinks or hardlinks. It performs no network request, writes no current pointer, and is not enrolled in production.

`runner/census-zcta-residual-geography.mjs` verifies the registered immutable national release and its selected state summary on every read. The application exposes verified availability—not an overlay toggle—and remains isolated from the existing state/ZCTA map. Residual-layer failure therefore cannot suppress or alter the existing state/ZCTA map.

# National business lifecycle industry-jurisdiction evidence v1.1

This immutable pointer-free successor rolls the selected EPA-refined exact-ZIP v1.1 evidence through the existing governed 60-scope disposition. It retains 51 state/D.C. scopes, five territories and four special scopes. Multi-state, unresolved, non-ZCTA and placeholder ZIP evidence is never allocated to states.

The rollup conserves all 48,194 ZIP5 keys and 8,011,213 source memberships. Mapped source-record union (6,780,627), unresolved records (1,230,586) and nonadditive industry assignments (6,782,745) remain separate. EPA retains its 1,517,826 records, 294,477 mapped union, 296,595 assignments, 2,107 multisegment records, 25,035 partially unmapped records and 1,223,349 unresolved records.

Each scope reports membership lifecycle/review totals, mapped/unresolved source records, nine industry assignment rows, EPA refinement details and fully unmapped FSIS evidence. Every industry retains an ordered source array with source-specific assignment, lifecycle and review counts. The residual unmapped array retains FSIS with its reason and source-specific temporal counts. EPA appears only in its six validated segments. The builder reconciles every scope against both retained v1 jurisdiction layers. The verifier replays all inputs and exact output bytes. Its governed mapping dependency is accurately identified as lifecycle ZIP evidence; no jurisdiction release is mislabeled as that source.

```text
npm run business-lifecycle-industry-jurisdiction:build
npm run business-lifecycle-industry-jurisdiction:verify
node --test runner/national-business-lifecycle-industry-jurisdiction-evidence-v1-1.test.mjs
```

Counts are source evidence, not unique or active businesses or completeness. No USPS ZIP-state, ZIP-prefix, reported-state, fractional or multi-state allocation is inferred. No network request, acquisition, pointer write or production enrollment occurs.

# Iowa childcare source discovery — September 8, 2026

Official documentation establishes public search and dashboards, but this bounded review did not verify a statewide center-only bulk delivery contract. No existing Iowa childcare state note was found in the scoped local search.

[Iowa HHS childcare information](https://hhs.iowa.gov/programs/programs-and-services/child-care) distinguishes licensed centers, child development homes and child care homes, and links the public search and Child Care Connect dashboard. Center licensing/renewal descriptions are not independent proof of present business operation. The public [search user guide](https://iachildcareconnect.org/wp-content/uploads/sites/2/2024/08/Child-Care-Search-User-Guide.pdf) describes downloading favorite-provider information; that does not establish a complete statewide export.

The linked [data-sharing process overview](https://hhs.iowa.gov/media/15170/download?inline=) concerns secure child care management system vendor integration. It is not a blanket access restriction on the public directory, nor a public anonymous bulk API specification. Do not require its agreement for public information without a source-specific basis, and do not use the secure integration as a workaround.

Next: establish a documented public-directory export or metadata endpoint, an exact center-only predicate, selected name/address/ZIP schema, status/date semantics and applicable reuse terms. No facility rows, ID inventory, source files, accounts, contacts or app dispatch were used. No statewide completeness or zero-business claim follows from the unresolved bulk contract.

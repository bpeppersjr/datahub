# NH public childcare license register: unsent request draft

Status: prepared for operator review only. No message sent, fee accepted, account created or source policy expanded. Verify the receiving DHHS records office and sender details before sending.

## Why this route

NH's [RSA 170-E:10](https://www.gc.nh.gov/rsa/html/XII/170-E/170-E-10.htm) distinguishes public licenses and licensing findings/decisions from confidential application information. [RSA 91-A:4](https://gc.nh.gov/rsa/html/VI/91-A/91-A-4.htm) describes access to existing government records, including electronic copies in common formats, but does not require a new compilation. Both official pages were inspected September 10, 2026. These provisions support investigating existing public licensing records; they do not establish a dataset's availability, guarantee disclosure of every requested field, or authorize unrestricted redistribution.

A single existing statewide release could avoid repeated ZIP searches and support local state/county/ZIP views. This is an acquisition-design inference, not evidence that such an export has been obtained.

## Draft

Subject: Existing public childcare license register in electronic format

Hello,

I am seeking the existing public register or export of New Hampshire childcare licenses, in the electronic format in which your department currently maintains or reports it. I am not asking for a newly compiled dataset or underlying application records.

Please provide the existing public business/license fields available in that register, such as license identifier, program name/type, publicly releasable program address, license status, and issue/effective/expiration dates. Please exclude confidential application, child, household and personnel information, and any protected address or contact fields.

If maintained, please also provide the register's existing field definitions, status-code definitions, data-as-of date, update frequency, and any published instructions about attribution or permitted reuse. An existing statewide download URL is welcome in place of a separate copy.

If a narrower existing report is more practical, please identify it. Please advise of any fees before proceeding; this request does not authorize charges.

Thank you,

[Sender name and reply address]

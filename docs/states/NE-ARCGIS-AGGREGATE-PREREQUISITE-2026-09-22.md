# Nebraska DHHS ArcGIS aggregate prerequisite

This implementation is limited to the exact DHHS Licensed Child Care ArcGIS item, its state-hosted FeatureServer and layer 0, plus two fixed aggregate queries for `Child Care Center` and `Provisional Child Care Center`. It never requests features, object IDs, home-provider identities, ZIPs or coordinates. The aggregate counts and date-only extrema are source-contract evidence only. The prior observed cohort (699 and 51 rows, each with roster date 2025-10-15) is historical and does not establish current businesses, coverage or a 2026 release.

## Policy gate

The 2026-09-09 source follow-up records the item's public-use context and exact publisher/service chain. The separate DHHS PDF policy assessment records a DHHS-linked Nebraska.gov notice that limits copying and requires prior permission for automated copying, while explicitly leaving its applicability to DHHS-hosted material unresolved. The current-edition investigation further says the ArcGIS cohort is dated October 15, 2025 and is not a current edition. This connector therefore does not treat public accessibility or the item notice as blanket authorization.

Native mode returns `HOLD` before allocating a run ID, output directory, intent, receipt, or manifest, and makes zero source requests unless the operator separately records `data/governance/ne-childcare-scope-decision.json`. This change does not create that file or approve a decision. `node scripts/preflight-ne-childcare-aggregate.mjs --decision-contract` displays the exact required schema/hash contract. The decision must contain exactly these own properties: `schema_version`, `decision_id`, `decision`, `decided_by`, `decided_at`, `rationale`, `scope_contract_sha256`, `connector_sha256`, `policy_sha256`, and `evidence`. Values are fixed to schema `ne-childcare-scope-decision@1.0.0`, id `NE-DHHS-ARCGIS-AGGREGATE-2026`, decision `approve-scoped-metadata-aggregate`, the runtime-computed scope hash, exact connector/policy byte hashes, and the three evidence paths and exact byte hashes printed by `--decision-contract`. `decided_by`, UTC millisecond timestamp, and rationale must be nonempty/valid. No additional fields or caller overrides are accepted. This disposition authorizes only this prerequisite scope, not acquisition or redistribution.

## Bounded request and evidence contract

There are exactly three metadata GETs and at most two aggregate GETs on the literal URLs declared in the connector and runner. Requests are sequential, separated by at least one second, limited to 15 seconds and 1,000,000 response bytes each, with manual redirect rejection, no retries, no alternate host/path/query and strict JSON, content-type, HTTP status, ArcGIS error, identity, schema and two-category aggregate checks. The two aggregate calls are distinct sequential reads and are **not an atomic snapshot**; cross-request conservation or consistency is not asserted.

Bodies are parsed in memory and discarded. The bundle stores an immutable intent, minimized receipt, and manifest published last. The verifier checks bundle hashes and fixed zero-row/no-promotion claims. Native output is under app `data/business-sources/ne-childcare-aggregate-preflight`; injected offline test evidence is under `data/tmp` and is removed by the tests. A cancelled or failed session preserves only its request metadata and no body. Nothing in this prerequisite selects provider records or adds Nebraska facilities to any coverage view.

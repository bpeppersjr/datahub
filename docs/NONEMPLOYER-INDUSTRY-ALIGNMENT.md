# Retained nonemployer industry alignment

Independent data-service contract; no UI, endpoint, acquisition, refresh or production pointer change. `readNonemployerIndustryAlignment({naics, referenceYear:2023, states?, signal?})` accepts exact NAICS 2022 codes and optional 50-state/DC FIPS labels. It reads the reviewed immutable 2023 NES release, not a mutable current pointer. State omission means all 51; an empty array displays none without changing the denominator.

The denominator is the official national row for the same NAICS, reference year, all legal forms (`001`) and all receipt sizes (`001`). Each state's percentage is its corresponding annual nonemployer establishment count divided by that national count. Never sum NAICS parents and children, legal-form subtotals or receipt-size bins. These are not feed counts, named-business counts, collection completeness, current operations, employer establishments, credentials or ZIP allocations.

Missing cells remain `not-published`; absent measures remain null. Uninterpreted nonempty measure, industry or geography flags yield `flagged-uninterpreted` with preserved flags and null count/percentage. A genuinely published zero remains zero, but a zero national denominator yields null percentages. State reconciliation uses all 51 states irrespective of display filters. An incomplete state universe yields a null residual; when all cells are usable, any signed national-minus-state difference remains explicit rather than being normalized away.

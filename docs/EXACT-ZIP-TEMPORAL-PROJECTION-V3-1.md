# Exact-ZIP temporal projection 3.1

Version 3.1 is a read-only temporal and provenance successor over the unchanged, hash-pinned 51-dimension v3.0 exact-ZIP evidence matrix. It performs no source request, changes no evidence cell, adds no business record, and writes no production pointer.

The predecessor left ten retained dimensions with `unmapped` temporal placeholders: CMS hospitals, CMS nursing homes, Pennsylvania, Connecticut, Maryland, Vermont, Colorado, Utah and Iowa childcare candidates, and Minnesota residential-construction credential rows. Version 3.1 binds each dimension to a stable source key and its retained source-release identity. All ten use `non-active-reporting` and `unmeasured` review semantics. This deliberately does not convert directory, provider-candidate or credential membership into verified current operation, a unique business, a physical operating site, completeness, or an additive business count. Utah and Iowa retain unresolved publisher reference dates even though their retained release identities are known.

The exact-ZIP API returns `exact-zip-industry-temporal-qualification-view@3.1.0` while preserving the underlying `national-exact-zip-industry-evidence-row@3.0.0` schema, matrix release ID, manifest hash, 48,194 ZIP5 keys, 51 dimensions and 2,457,894 evidence cells. `GET /api/business-map/exact-zip-industry-summary` now serves `national-exact-zip-industry-summary-view@3.1.0`; it continues to reject query options. Industry Status validates, renders and downloads that governed summary through its existing JSON action.

The national projection reads the hash-verified `00000` matrix prefix to obtain the ten previously missing retained evidence-release identities and publisher reference values. CMS directory dimensions retain their shared directory-evidence release, childcare candidates retain their shared childcare-evidence release, and Minnesota retains its credential release. These are the matrix's evidence-release identities; they are not newly acquired source versions. Utah and Iowa reference dates remain null. This is bounded recursive lineage verification, not a full national matrix replay.

The closed v3.1 UI contract pins the matrix identity, all 51 dimension IDs, counts and temporal provenance. It independently reconstructs joined dispositions and reconciles per-dimension rows, aggregate lifecycle counts and source-specific disposition arrays. Unknown fields or versions, missing or changed release identities, balanced count/semantic redistributions, and elevated operation, identity-merge, completeness or additivity flags fail closed. Historical v2.0–v3.0 validators remain available for existing callers.

Review qualification now conserves 29 dimensions within review window, two stale, twenty unmeasured and zero unmapped. Recomputed semantic totals conserve 25 source-defined-current, twenty non-active-reporting, one annual aggregate, one linkage-readiness, three publisher-active-snapshot and one unknown-source-status dimension. These totals follow the dimension rows; the predecessor's incrementally maintained semantic aggregate overstated source-defined-current by one. Raw cell counts and all 2,457,894 evidence cells are unchanged. The inherited assessment timestamp and temporal provenance registration identify the retained predecessor inputs rather than a newly published temporal artifact; legacy `temporal_status_counts` remains the unchanged predecessor cohort field, not a new 51-dimension temporal total.

Focused runtime tests conserve the full cell total and raw states, eliminate the ten temporal placeholders, bind all ten release identities/reference values to hash-verified matrix cells, and keep current-operation and all-business-completeness claims false. UI tests render every new mapping and release identity, reject malformed responses and contract drift, and exercise the unavailable state without inferred zero or percentages. No production runtime, source refresh, source pointer or production plan is changed by this integration.

# Census NAICS reference

`us-census-naics-reference@1.0.0` retains official Census exact code/title references for 1997, 2002, 2007, 2012, 2017, and 2022. This application-owned standalone runner works without Codex, ChatGPT, credentials, or a browser.

Run `npm run naics-reference:build -- --acquire` for the six small public reference files. Run `npm run naics-reference:build -- --replay <manifest>` for zero-network deterministic reconstruction of a retained release. Run `npm run naics-reference:verify -- <manifest>` to replay every native source and check exact normalized bytes, checksums, contract hashes, edition summaries, claim boundaries, and content address. Cancellation through SIGINT/SIGTERM records a terminal receipt. New operations get separate run directories; interrupted runs restart under a new run ID. There are no automatic retries or partial resume.

The [Census NAICS page](https://www.census.gov/naics/) supplies the 2017 and 2022 United States structure XLSX files. Parsing is bounded to the first worksheet, exact B/C code/title columns, and A change indicator. The 2017 workbook's two extra worksheets must be empty. Superscript T is retained as a trilateral marker rather than appended to the title; this does not assert international comparability below that level. Native workbooks preserve all formatting and notes.

The [Census SUSB industry reference page](https://www.census.gov/programs-surveys/susb/technical-documentation/reference-files/industry-reference-files.html) explicitly binds its 1998–2002, 2003–2007, 2008–2011, and 2012–2016 TXT lists to NAICS editions 1997, 2002, 2007, and 2012. These four vocabularies have SUSB publication scope, which excludes some NAICS industries. Absence from these lists cannot establish that a code is invalid. The 2012 TXT is used because parsing the legacy structure XLS would require a separate parser dependency. No such dependency was added. Windows-1252 decodes the historical lists; native bytes remain intact. The `-- Total` marker is excluded; combined sectors 31-33, 44-45, 48-49 retain their exact strings without expansion. Titles are source spellings with outer whitespace trimmed.

Each row carries explicit edition, source row, URL, native SHA-256, authority scope, policy, and transformation. Exact code membership never determines an unknown source edition. No concordance, operational mapping, primary industry assignment, business count, or completeness claim is produced. This reference does not change EPA releases, the industry matrix, or application runtime pointers.

Network requests use six fixed HTTPS URLs, one at a time, a 60-second timeout, a one-million-byte source bound, expected media types, and redirect rejection. Workbook parsing bounds archive parts and expansion and rejects formulas, external relationships, encrypted parts, active content, duplicate codes, and drifted headers. All paths and operation receipts remain inside datahub. Manifests publish after artifacts and verification, under a content-derived immutable release ID. Identical reruns verify and reuse the retained release; concurrency cannot overwrite it.

Rollback consists of removing the connector registration and scripts from a later reviewed code change; retained releases remain readable and no current pointer requires restoration. The connector has a CLI execution entry point; it is not yet an Administration queue or scheduler operation.

`node scripts/build-us-census-naics-reference.mjs --recover-run <failed-run-id>` reuses checksummed native files from a terminal failed/cancelled operation and acquires only missing sources. Each reused file must match the prior persisted acquisition receipt; changed files fail before publication. Recovery builds in a new run directory and repeats all parsing/quality checks. Completed immutable releases should use `--replay` instead.

An explicit `--rebind-contracts <manifest>` performs zero-network native reprocessing under current connector/schema/policy hashes after a contract correction. It verifies the input's content address, every native and derived artifact checksum, source roster, claim boundaries, and current parsing/quality of the native sources. It then produces and fully replay-verifies a new immutable release. It does not certify historical contract availability or historical derived semantics, and never changes the old release. Ordinary verification and `--replay` require current contract hashes to match and verify all derived semantics. Census policy references are the [Policies and Notices page](https://www.census.gov/about/policies.html) and [Research Transparency and Public Access policy DS027](https://www2.census.gov/foia/ds_policies/ds027.pdf).

Code `99` in the historical SUSB lists is retained as `source-program-unclassified`, with a separate summary count. It is a source program's unclassified marker and is excluded from ordinary exact NAICS code and digit-level counts. Each edition's vocabulary count reconciles exact codes, three combined sectors, and any source program markers.

Native workbooks preserve public publisher document-author metadata, which can name Census staff. The policy declares that limited personal metadata scope; normalized classification rows contain no person records.

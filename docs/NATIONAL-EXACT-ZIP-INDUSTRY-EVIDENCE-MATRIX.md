# National exact-ZIP industry evidence matrix

The current successor is immutable, pointer-free, and local-review-only v1.8.0. It composes thirty-nine separately identified, already-retained source projections over the exact 48,194-member `zip-denominator-gap-cohort`: nine national overlays; separate CMS hospital and nursing-home directory rows; seven publisher-specific childcare candidate-row dimensions (PA, CT, MD, VT, CO, UT, IA); four publisher-specific childcare reporting-center dimensions (MA, NJ, TN, OH); eight publisher-specific registry-location-profile cohorts; and nine broad-organization address-row dimensions (CO, CT, DE, FL, IA, NY, OR legal registrations, OR assumed-name brands, PA). No acquisition or network access occurs, and this matrix is not enrolled in production. Historical v1.7.0 and earlier releases remain immutable; v1.8.0 pins the exact v1.7.0 predecessor release and manifest hash.

Each exact-ZIP row preserves `zip5`, keeps `zip4` as `null`, retains cohort classification and a ZCTA identifier where present, and leaves USPS validity `null`. Every cell carries its source-specific measure, release, and temporal status. Source reference dates, measure units, publisher identity, source policy, retained provenance, and source semantics are bound per source and surfaced by bounded lookup. A closed per-dimension `zero_evidence_semantics` contract distinguishes dimensions with exact-ZIP denominators, dimensions whose absent keys are outside their source denominator, and state/local whole-cohort extracts without a nationwide denominator. For the latter, missing source rows are `absent-from-retained-source-rows` with `count: null`, not a numeric zero; they are not evidence of ZIP membership or completeness. A same-code ZCTA never supplies publisher jurisdiction or an exact-ZIP source denominator. Explicit retained zero rows remain `measured-zero` with `count: 0` only where that source contract permits them. A governed reference date yields `source-referenced-current-operation-unverified`; missing source reference dates remain `source-reference-unresolved`. Neither status asserts present-day operation.

Downstream presentations derive a nullable display value from the closed cell status: `positive` displays its positive integer, `measured-zero` displays `0`, and both `outside-source-denominator` and `absent-from-retained-source-rows` display “Not measured.” In v1.8 the stored values are consistent with those meanings: positive is a positive integer, measured-zero is numeric zero, and both unmeasured statuses are null. Unknown or inconsistent status/value pairs are rejected, not coerced. ZIP GDP segmentation preserves each cell and this source-measure value alongside exact matrix `release_id` and `manifest_sha256` provenance; it does not turn source counts into GDP estimates or alter completion claims.

The seven childcare candidate dimensions are governed by the immutable retained-childcare ZIP release and its independently replayed native reader. Each uses publisher candidate rows and internal-only export policy. The retained inputs report 12,206 candidate rows across sources, 12,205 with ZIP5, zero missing ZIP candidates, and one Maryland candidate categorized by the source contract as `invalid-source-zip-range`. That quality exception is preserved separately in `source-quality-gaps.json` with `zip5: null`; it is not assigned a ZIP. Maryland ZIP5 `21708` is instead a distinct positive out-of-cohort source ZIP gap. It is not added to the cohort or characterized as an invalid USPS ZIP. No childcare public export, national denominator enrollment, production enrollment, identity merge, or current-operation claim is authorized by this matrix.

The four reporting-center dimensions replay only the 10 pinned MA/NJ/TN/OH `reporting/location-evidence` ZIP2 artifacts from retained national-business-registry release `national-business-registry-20260911-022652067Z-1ec656c3` (manifest SHA-256 `d8ab131697b1df63ed53fdfa9832d6973fd152ddf23565219ee9bb39b25fbb76`). Measures remain `reported_center_rows`; rows are separate publisher cohorts, are not identity-merged, and are not verified operating businesses. Source labels stay distinct: MA Current 2,561 / Renewal in progress 431 / Expired 13 / Regional Enrollment Freeze 2; NJ null-status layer membership 4,075; TN Active 1,863; OH Open 4,237. Every row remains local-review-only, `identity_matching_eligible:false`, and `active_business_verified:false`. TN’s 27 `missing-source-zip` and 145 source-classified `invalid-source-zip-placeholder` rows remain distinct null-ZIP quality gaps; they are neither positive out-of-cohort ZIP keys nor the separate Maryland `invalid-source-zip-range` candidate exception. ZIP+4 is retained only as metadata, coordinates never fill ZIP, and all 4,237 OH coordinates remain ineligible for governed geography. The nine broad-organization dimensions use the exact selected, retained v1.0 eight-publisher release (CO, CT, DE, FL, IA, NY, OR, PA; no AK) through a bounded pointer-free ZIP5 summary derivative. Seven dimensions retain organization-address rows (including DE license-address rows under the stricter local-review-only ceiling); Oregon legal-registration and assumed-name brand-address rows stay separate.

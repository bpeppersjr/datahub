# National exact-ZIP industry evidence matrix

The current registered release is immutable, pointer-free, and local-review-only v1.3.0. It composes eighteen separately identified, already-retained source projections over the exact 48,194-member `zip-denominator-gap-cohort`: nine national overlays, separate CMS hospital and nursing-home directory rows, and seven publisher-specific childcare candidate-row dimensions (PA, CT, MD, VT, CO, UT, IA). Childcare sources are not merged, deduplicated, or represented as business, physical-site, establishment, or current-operation counts. No acquisition or network access occurs, and this matrix is not enrolled in production.

Each exact-ZIP row preserves `zip5`, keeps `zip4` as `null`, retains cohort classification and a ZCTA identifier where present, and leaves USPS validity `null`. Every cell carries its source-specific measure, release, and temporal status. Source reference dates, measure units, publisher identity, source policy, retained provenance, and source semantics are bound per source and surfaced by bounded lookup. A governed reference date yields `source-referenced-current-operation-unverified`; missing source reference dates remain `source-reference-unresolved`. Neither status asserts present-day operation.

The seven childcare dimensions are governed by the immutable retained-childcare ZIP release and its independently replayed native reader. Each uses publisher candidate rows and internal-only export policy. The retained inputs report 12,206 candidate rows across sources, 12,205 with ZIP5, zero missing ZIP candidates, and one Maryland candidate categorized by the source contract as `invalid-source-zip-range`. That quality exception is preserved separately in `source-quality-gaps.json` with `zip5: null`; it is not assigned a ZIP. Maryland ZIP5 `21708` is instead a distinct positive out-of-cohort source ZIP gap. It is not added to the cohort or characterized as an invalid USPS ZIP. No childcare public export, national denominator enrollment, production enrollment, identity merge, or current-operation claim is authorized by this matrix.

Out-of-cohort positive source ZIP keys are preserved in `out-of-cohort-source-zip-gaps.json`; the sidecar currently retains Maryland childcare ZIP5 `21708` and CMS nursing-home ZIP5 keys `35999` and `73706`. Such records document source evidence outside the exact cohort and do not classify USPS validity or imply zero activity. The separate source-quality sidecar preserves the Maryland non-ZIP source quality exception.

The registered v1.3.0 release contains 48,194 ZIP rows and 867,492 cells: 226,171 positive, 583,869 measured-zero, and 57,452 outside-source-denominator. It binds the current pinned CMS retained directory ZIP evidence and childcare ZIP evidence registrations directly and replays their source artifacts; it does not substitute an in-memory source layer. Historical matrix releases remain immutable.

Bounded lookup reads only the pinned manifest, one prefix bucket, and the two small gap sidecars. It reports `full_matrix_replay_performed: false`; independent release verification performs full source replay. Cell counts are source-specific and nonadditive. No cross-industry totals, completeness estimates, ZIP+4 joins, authoritative USPS denominator, valid-USPS classification, business identity merges, or current-operation claims are made.

Build with `npm run exact-zip-industry-matrix:build` and verify the registered release with `npm run exact-zip-industry-matrix:verify`.

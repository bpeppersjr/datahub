# National exact-ZIP industry evidence matrix

The current successor is immutable, pointer-free, and local-review-only v1.7.0. It composes thirty-nine separately identified, already-retained source projections over the exact 48,194-member `zip-denominator-gap-cohort`: nine national overlays; separate CMS hospital and nursing-home directory rows; seven publisher-specific childcare candidate-row dimensions (PA, CT, MD, VT, CO, UT, IA); four publisher-specific childcare reporting-center dimensions (MA, NJ, TN, OH); eight publisher-specific registry-location-profile cohorts; and nine broad-organization address-row dimensions (CO, CT, DE, FL, IA, NY, OR legal registrations, OR assumed-name brands, PA). No acquisition or network access occurs, and this matrix is not enrolled in production. Historical v1.6.0 and earlier releases remain immutable.

Each exact-ZIP row preserves `zip5`, keeps `zip4` as `null`, retains cohort classification and a ZCTA identifier where present, and leaves USPS validity `null`. Every cell carries its source-specific measure, release, and temporal status. Source reference dates, measure units, publisher identity, source policy, retained provenance, and source semantics are bound per source and surfaced by bounded lookup. A closed per-dimension `zero_evidence_semantics` contract distinguishes dimensions with exact-ZIP denominators, dimensions whose absent keys are outside their source denominator, and state/local whole-cohort extracts without a nationwide denominator. For the latter, missing source rows are `absent-from-retained-source-rows` with count 0; this is not measured zero, evidence of ZIP membership, or completeness. A same-code ZCTA never supplies publisher jurisdiction or an exact-ZIP source denominator. Explicit retained zero rows remain `measured-zero` only where that source contract permits them. A governed reference date yields `source-referenced-current-operation-unverified`; missing source reference dates remain `source-reference-unresolved`. Neither status asserts present-day operation.

Downstream presentations derive a nullable display value from the closed cell status, without modifying matrix cells: `positive` displays its positive integer, `measured-zero` displays `0`, and both `outside-source-denominator` and `absent-from-retained-source-rows` display “Not measured.” Unknown statuses are rejected, not coerced to zero. ZIP GDP segmentation preserves each cell and this source-measure value alongside explicit v1.7 matrix `release_id` and `manifest_sha256` provenance; it does not turn source counts into GDP estimates or alter completion claims.

The seven childcare candidate dimensions are governed by the immutable retained-childcare ZIP release and its independently replayed native reader. Each uses publisher candidate rows and internal-only export policy. The retained inputs report 12,206 candidate rows across sources, 12,205 with ZIP5, zero missing ZIP candidates, and one Maryland candidate categorized by the source contract as `invalid-source-zip-range`. That quality exception is preserved separately in `source-quality-gaps.json` with `zip5: null`; it is not assigned a ZIP. Maryland ZIP5 `21708` is instead a distinct positive out-of-cohort source ZIP gap. It is not added to the cohort or characterized as an invalid USPS ZIP. No childcare public export, national denominator enrollment, production enrollment, identity merge, or current-operation claim is authorized by this matrix.

The four reporting-center dimensions replay only the 10 pinned MA/NJ/TN/OH `reporting/location-evidence` ZIP2 artifacts from retained national-business-registry release `national-business-registry-20260911-022652067Z-1ec656c3` (manifest SHA-256 `d8ab131697b1df63ed53fdfa9832d6973fd152ddf23565219ee9bb39b25fbb76`). They preserve 13,182 publisher-reported center rows, 13,010 ZIP-bearing rows, and a 1,964-ZIP union, with zero out-of-cohort ZIPs. Measures remain `reported_center_rows`; rows are separate publisher cohorts, are not identity-merged, and are not verified operating businesses. Source labels stay distinct: MA Current 2,561 / Renewal in progress 431 / Expired 13 / Regional Enrollment Freeze 2; NJ null-status layer membership 4,075; TN Active 1,863; OH Open 4,237. Every row remains local-review-only, `identity_matching_eligible:false`, and `active_business_verified:false`. TN’s 27 `missing-source-zip` and 145 source-classified `invalid-source-zip-placeholder` rows remain distinct null-ZIP quality gaps; they are neither positive out-of-cohort ZIP keys nor the separate Maryland `invalid-source-zip-range` candidate exception. ZIP+4 is retained only as metadata, coordinates never fill ZIP, and all 4,237 OH coordinates remain ineligible for governed geography. Source observation ranges are not refresh clocks; particularly, OH’s reprocessed manifest clock is not substituted for the row-level observation interval.

The nine broad-organization dimensions use the exact selected, retained v1.0 eight-publisher release (CO, CT, DE, FL, IA, NY, OR, PA; no AK) through a bounded pointer-free ZIP5 summary derivative. Seven dimensions retain organization-address rows (including DE license-address rows under the stricter local-review-only ceiling); Oregon legal-registration and assumed-name brand-address rows stay separate. The summary pins the selected registration, upstream manifest, all 108 prefix and missing/ineligible artifacts, eight native source manifests, policies, transforms, source reference dates, and row-unit semantics. Its source conservation is 14,340,575 input records to 14,340,583 address rows: 9,940,777 eligible ZIP rows, 4,399,806 missing/ineligible rows, 30,802 ZIPs, and zero source ZIPs outside the exact cohort. Oregon legal and brand rows are 443,123 and 116,407 respectively. These are publisher-specific source-reported address rows, not additive businesses, people, physical sites, establishments, or current operations. Publisher jurisdiction can differ from reported-address jurisdiction. ZIP4 remains separate, and USPS validity remains unknown.

The eight added registry-location-profile dimensions consume the already-registered `zip-source-native-status-distribution` release `zip-source-native-status-f6ae96364838baab402d8bcd487cac04059f910af1b71bb9da6bf19424d50640` (manifest SHA-256 `0d244bf8622d83089153c142837b9078db049d7b521c34bf76471831cedfb338`). The matrix builder checks the registration and manifest pins, verifies the 100 retained ZIP2 data buckets, and filters only AK, CA ABC, Chicago, D.C. basic licenses, Los Angeles, NY retail food, NYC DCWP, and Texas sales-tax profiles; the other seven status-distribution cohorts are not re-added because they already have matrix dimensions. The underlying 15-source status distribution contains 8,011,835 profiles; the eight selected and newly integrated dimensions conserve 1,850,619 profiles over a 12,454-ZIP union, all within the existing ZIP cohort, with zero out-of-cohort ZIP rows. Manifest fields keep those input and selected totals separate. Per-ZIP cells preserve `present`, `empty-object`, `missing`, and `null` status counts without exposing profile IDs, raw statuses, or status digests. LA's 633,232 profiles have null status; the other 1,217,387 have present status. Native source reference dates remain distinct from source-observation timestamps; for example, NY retail food references 2025-09-30 while its observed-at clock is separately retained. Refresh time is not asserted. These source-native registration/location profiles are nonadditive and do not establish unique businesses, physical sites, or current operation; cross-source business overlap is unresolved. Export policy remains `local-review-only`.

Out-of-cohort positive source ZIP keys are preserved in `out-of-cohort-source-zip-gaps.json`; the sidecar retains Maryland childcare ZIP5 `21708` and CMS nursing-home ZIP5 keys `35999` and `73706`. The selected broad-organization release has zero out-of-cohort ZIPs. Source-address rows without eligible ZIP5 are preserved separately in `source-address-row-gaps.json` with publisher, record kind/dimension, original ZIP partition reason, row count, source release/manifest, and source reference date; these are not ZIP-key gaps and make no USPS classification. The separate `source-quality-gaps.json` preserves the Maryland childcare non-ZIP `invalid-source-zip-range` candidate exception. These three gap concepts are not interchangeable.

The registered v1.7.0 release contains 48,194 ZIP rows and 1,879,566 cells (48,194 × 39). It preserves 336,058 positive cells and 57,452 outside-source-denominator cells, and reclassifies exactly 1,237,187 state/local absences from the historical measured-zero label to `absent-from-retained-source-rows`; the remaining 248,869 measured-zero cells are backed by source contracts that permit explicit zero evidence. Per-dimension status counts conserve exactly 48,194 cells each. The manifest also binds source-reference dates and source-observation ranges, the pinned CMS retained directory ZIP evidence, childcare candidate and reporting evidence, broad-organization ZIP summary, and native-status distribution directly, preserving previous releases as immutable history. These classifications describe retained evidence availability only, not the number of businesses or nationwide completeness.

Bounded lookup reads only the pinned manifest, one prefix bucket, and three separate gap sidecars. The 39-source prefix size is capped at 16,000,000 bytes before publication and on read; the prefix reader stats an already-open file before allocation. Lookup reports `full_matrix_replay_performed: false`; independent release verification performs full source replay. Cell counts are source-specific and nonadditive. No cross-industry totals, completeness estimates, ZIP+4 joins, authoritative USPS denominator, valid-USPS classification, business identity merges, or current-operation claims are made.

Build the bounded broad-organization derivative offline with `npm run broad-org-zip-summary:build`, verify it with `npm run broad-org-zip-summary:verify`, then build and verify the matrix with `npm run exact-zip-industry-matrix:build` and `npm run exact-zip-industry-matrix:verify`. The registered native-status release is reused as-is; no source acquisition or new summary family is required. The immutable releases under `data/` are local retained artifacts and are intentionally excluded from Git; commits carry the registration pins, builders, readers, tests, and documentation, not the retained evidence payloads. Verification fails closed if a pinned local release is missing or differs from its registered hashes.

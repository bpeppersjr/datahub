# National exact-ZIP industry evidence matrix

The current registered release is immutable, pointer-free, and local-review-only v1.4.0. It composes twenty-seven separately identified, already-retained source projections over the exact 48,194-member `zip-denominator-gap-cohort`: nine national overlays; separate CMS hospital and nursing-home directory rows; seven publisher-specific childcare candidate-row dimensions (PA, CT, MD, VT, CO, UT, IA); and nine broad-organization address-row dimensions (CO, CT, DE, FL, IA, NY, OR legal registrations, OR assumed-name brands, PA). No acquisition or network access occurs, and this matrix is not enrolled in production.

Each exact-ZIP row preserves `zip5`, keeps `zip4` as `null`, retains cohort classification and a ZCTA identifier where present, and leaves USPS validity `null`. Every cell carries its source-specific measure, release, and temporal status. Source reference dates, measure units, publisher identity, source policy, retained provenance, and source semantics are bound per source and surfaced by bounded lookup. A governed reference date yields `source-referenced-current-operation-unverified`; missing source reference dates remain `source-reference-unresolved`. Neither status asserts present-day operation.

The seven childcare dimensions are governed by the immutable retained-childcare ZIP release and its independently replayed native reader. Each uses publisher candidate rows and internal-only export policy. The retained inputs report 12,206 candidate rows across sources, 12,205 with ZIP5, zero missing ZIP candidates, and one Maryland candidate categorized by the source contract as `invalid-source-zip-range`. That quality exception is preserved separately in `source-quality-gaps.json` with `zip5: null`; it is not assigned a ZIP. Maryland ZIP5 `21708` is instead a distinct positive out-of-cohort source ZIP gap. It is not added to the cohort or characterized as an invalid USPS ZIP. No childcare public export, national denominator enrollment, production enrollment, identity merge, or current-operation claim is authorized by this matrix.

The nine broad-organization dimensions use the exact selected, retained v1.0 eight-publisher release (CO, CT, DE, FL, IA, NY, OR, PA; no AK) through a bounded pointer-free ZIP5 summary derivative. Seven dimensions retain organization-address rows (including DE license-address rows under the stricter local-review-only ceiling); Oregon legal-registration and assumed-name brand-address rows stay separate. The summary pins the selected registration, upstream manifest, all 108 prefix and missing/ineligible artifacts, eight native source manifests, policies, transforms, source reference dates, and row-unit semantics. Its source conservation is 14,340,575 input records to 14,340,583 address rows: 9,940,777 eligible ZIP rows, 4,399,806 missing/ineligible rows, 30,802 ZIPs, and zero source ZIPs outside the exact cohort. Oregon legal and brand rows are 443,123 and 116,407 respectively. These are publisher-specific source-reported address rows, not additive businesses, people, physical sites, establishments, or current operations. Publisher jurisdiction can differ from reported-address jurisdiction. ZIP4 remains separate, and USPS validity remains unknown.

Out-of-cohort positive source ZIP keys are preserved in `out-of-cohort-source-zip-gaps.json`; the sidecar retains Maryland childcare ZIP5 `21708` and CMS nursing-home ZIP5 keys `35999` and `73706`. The selected broad-organization release has zero out-of-cohort ZIPs. Source-address rows without eligible ZIP5 are preserved separately in `source-address-row-gaps.json` with publisher, record kind/dimension, original ZIP partition reason, row count, source release/manifest, and source reference date; these are not ZIP-key gaps and make no USPS classification. The separate `source-quality-gaps.json` preserves the Maryland childcare non-ZIP `invalid-source-zip-range` candidate exception. These three gap concepts are not interchangeable.

The registered v1.4.0 release contains 48,194 ZIP rows and 1,301,238 cells. Its manifest reports source-specific positive, measured-zero, and outside-source-denominator totals. It binds the pinned CMS retained directory ZIP evidence, retained childcare ZIP evidence, and selected broad-organization ZIP summary directly, deeply replaying their sources and preserving an immutable historical release chain.

Bounded lookup reads only the pinned manifest, one prefix bucket, and three separate gap sidecars. The 27-source prefix size is bounded by the reader's explicit byte ceiling and measured artifact sizes in the registered release. Lookup reports `full_matrix_replay_performed: false`; independent release verification performs full source replay. Cell counts are source-specific and nonadditive. No cross-industry totals, completeness estimates, ZIP+4 joins, authoritative USPS denominator, valid-USPS classification, business identity merges, or current-operation claims are made.

Build the bounded broad-organization derivative offline with `npm run broad-org-zip-summary:build`, verify it with `npm run broad-org-zip-summary:verify`, then build and verify the matrix with `npm run exact-zip-industry-matrix:build` and `npm run exact-zip-industry-matrix:verify`. The immutable releases under `data/` are local retained artifacts and are intentionally excluded from Git; commits carry the registration pins, builders, readers, tests, and documentation, not the retained evidence payloads. Verification fails closed if a pinned local release is missing or differs from its registered hashes.

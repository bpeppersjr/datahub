Removing the dataset registration disables this release's selection; historical source releases and application production pointers remain available for rollback.

## Application integration

Industry Status now includes a compact National Status panel with national cohort, dimension/cell and state/industry counts, review dates, gaps, national industry evidence reach, separate geography scopes/territories, selected-state source detail and a five-digit ZIP inspector. Each request loads independently and is cancelled when its selector changes. A failed summary, state or ZIP request leaves existing Industry Status, EPA evidence and map views available.

The authenticated read-only endpoints are `GET /api/business-map/national-status-summary` (no query), `GET /api/business-map/national-status-state?state=NJ` (one state/DC abbreviation), and `GET /api/business-map/national-status-zip?zip=10001` (one exact ZIP5 string). Other methods, bodies, repeated/unknown query keys and territory-as-state selectors are rejected. Responses use `national-status-view@1.0.0`, closed claims and exact release/artifact provenance. Errors disclose no paths or underlying exception detail.

The reader selects the fixed registered release and exact compiled manifest pin. Secure bounded reads reject symlink ancestry, changed file identity, checksum drift and unstable release selection. Summary reads the 52KB national summary plus bounded gap and territory aggregates; state reads the 1.73MB status artifact, validates exactly 459 distinct state/industry rows and returns nine. ZIP reads that bounded state artifact for available source temporal qualification and exactly one first-two-digit gzip partition. ZIP decompression is capped at 3MB, compressed input at 64KB, rows at 1,200 and lines at 32KB; every row is checked for exact prefix, order, 51 evidence statuses and separate ZIP4. Each response is capped at 128KB.

National and state metrics reconcile named numerators/denominators. State ZIP scopes conserve 33,455 dominant-state ZCTA keys; territories conserve 149 keys, and all 60 scopes conserve 48,194 keys. Source qualification is retained where the operational-industry rows provide it; unmapped ZIP dimensions expose the pinned matrix release and explicitly unmeasured temporal qualification. A ZIP outside the cohort returns `found:false`, null geography and no dimensions; absence does not establish USPS invalidity or zero businesses. Runtime performs no upstream replay, acquisition, writes, release publication or production enrollment. Removing the integration or reverting these application files restores the prior UI without changing the immutable release.

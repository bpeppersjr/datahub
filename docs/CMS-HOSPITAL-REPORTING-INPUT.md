# Retained CMS hospital reporting input

`loadCmsHospitalReportingInput({signal})` is a standalone local data-service helper, not registry enrollment. Its closed config `config/cms-hospital-retained-selection.json` must match the exact reviewed native acquisition manifest/hash. No source overrides, fetches, output artifacts or fallback acquisitions exist. The loader invokes the native acquisition verifier, reads the bounded selected artifact with stable ownership/hash/byte checks, preserves all selected records verbatim, then replays the verifier and rechecks selection stability before returning an immutable snapshot. The existing selected file is sufficient; no redundant normalization artifact is built.

The expected cohort is 5,419 CMS hospital directory rows. Native pins and acquisition evidence are recorded in `CMS-HOSPITAL-RETAINED-ADOPTION-HANDOFF-2026-09-12.md`. Identifier scope remains `cms-pdc-hospital-facility-id`, with six alphanumeric characters supported. ZIP5 and ZIP4 remain separate strings/nulls; observation, source dates, county labels, publisher-reported values and unknown NPI/company/current-operations/geocode fields remain unchanged. Exact source replay and selected-file hash bind full membership, not just row counts.

`summarizeCmsHospitalReporting(snapshot, {states?, zip5s?, signal?})` accepts only a helper-created immutable snapshot. State and ZIP filters intersect; omitted means unfiltered and an empty array selects no rows. `states` accepts the 50 states, D.C. and five territories. Unknown source states and missing ZIPs remain visible in unfiltered results, including null grouping keys; ZIP4 is never aggregated. Output groups by reported state and reported state plus ZIP5, not polygon membership. Rows absent after filtering are not fabricated zero-valued geographic features.

Percentages use two fixed full-input denominators: all retained directory rows and retained 50-state/D.C. rows. Territory and unknown-state groups have null state/D.C. percentages. Filtering never recomputes those denominators or normalizes displayed shares to 100 percent. Native expected totals are 5,419 all-source, 5,354 state/D.C., 65 territories, zero unknown states. These are cohort shares, not nationwide hospital/business completeness. Business, physical-site, current-operating and national-completeness counts/percentages remain null; export policy remains local-review-only, public export false.

`cmsHospitalReportingFixture` is a pure synthetic aggregate-testing seam. It permanently labels snapshots synthetic and native-source verification false; it cannot satisfy native retained loading. Fixture tests cover fixed selection rejection, source identity/postal preservation, duplicate/malformed membership, immutable snapshots, denominators/territories/unknowns, empty selections, strict dense filters and pre-abort behavior. Native retained proof is a separate review-gated step; fixture success does not claim native proof.

Cancellation proof boundary: this reporting helper's tests exercise pre-abort, not cancellation mid-read or mid-replay. The native loader forwards the signal into the existing yielding verifier and bounded line reader; no injected verifier or I/O bypass is exposed merely to test that path. Underlying cancellation coverage does not substitute for a dedicated midstream reporting-loader test.

No global registry, production pointer, server, UI or scheduling behavior changes.

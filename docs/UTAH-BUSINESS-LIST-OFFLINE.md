# Utah Business List offline contract

This bounded connector implements the schema published by Utah's [Business List Service](https://secure.utah.gov/datarequest/businesses/index.html) and its [three-sheet example](https://secure.utah.gov/datarequest/businesses/listExample.html). The service says a full list costs $0.01 per record and is updated through the previous Tuesday. This implementation does not authorize or perform that purchase.

Only an operator-supplied closed package beneath `data/imports/utah-business-list/packages/` is accepted. It must retain the original delivered workbook and separately contain three operator-derived JSONL exports. The validator pins the workbook and derived files by exact filenames, hashes, byte sizes, row counts, transformation declaration, and cross-sheet Entity ID references. It does not parse the workbook or prove the derived rows can be reproduced from it. Accordingly, output says `operator-derived-jsonl`, `source_native: false`, `source_authenticity_verified: false`, `reproducible_extraction_verified: false`, and `admission_eligible: false`. It performs zero network requests and writes no release, current pointer, or national admission.

The normalized result is provisional organization-level registration evidence from the operator-derived `BUSENTITY` export. It excludes Applicant Name and does not emit `BUSINFO` or `PRINCIPAL`, because those sheets can contain officers, principals, partners, registered agents, and other natural-person information. Source address and status are explicitly administrative registration evidence, not proof of a physical site or current business operation. ZIP5 and ZIP4 remain separate. No output may be admitted until an independent original-byte authenticity check and a deterministic workbook-to-JSONL replay establish equivalence.

# CMS hospital coverage extension

The optional `cms-hospital-coverage-extension@1.0.0` envelope consumes the verified typed registry hospital declaration and exact native retained source. Base coverage version selection is unchanged; neither Ohio nor Tennessee is required. Historical releases remain valid. This does not enroll a ninth source in the existing eight-source reporting catalog.

The extension adds separate hospital-directory row metrics, never canonical business, site, current-operation or completeness counts. National denominators remain the full retained cohort and the 50-state-plus-DC cohort through geographic filtering. Territory and unknown-state buckets remain explicit. State and ZIP views describe reported address values, not inferred Census membership. ZIP+4 is not grouped. Counties remain unknown, not zero.

`reporting/cms-hospitals/state-zips.jsonl` conserves every source row, including missing ZIP/state and rows outside the existing view universe. Declaration counters identify unrepresented state and ZIP rows. The source-only artifact is local-review-only. Shared views preserve their existing policy: retained-childcare-only stays internal; the pre-existing MN credential policy remains local-review-only when MN is present. CMS does not grant broader rights to unrelated inputs.

The verifier pins both the original registry manifest and its retained internal copy, replays the complete native source/registry membership, recomputes every embedded metric and complete state/ZIP grouping, and checks artifact hashes, bytes and counts. Final reverse reads check stable identity/hash of output artifacts, both registry manifests, and output-directory ownership. The native entry point accepts no mutation hook; a separate test entry is confined to data/tmp.

Focused synthetic tests cover conservation, missing cells, duplicate identifiers/views, invalid ZIPs, policy combinations, orphan artifacts and pre-abort. A gated tiny coverage-builder integration (`DATAHUB_TEST_CMS_RETAINED=1`) uses the byte-identical retained CMS copy with networking disabled: 5,419 source rows, 5,354 states/DC and 65 territory rows, unchanged legacy coverage counts, base coverage 2.8 without Ohio, declaration tamper rejection and saved-registry mutation during verification. This is retained local validation, not acquisition or production promotion. Global catalog/UI adoption and production pointers remain unchanged.

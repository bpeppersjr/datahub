# Kentucky business-entity bulk offline fixture contract

This connector implements only the Kentucky Secretary of State's published 42-field company-family layout for All Companies, New Companies Weekly, New Companies, and Company Changes. It is a fixture-only, offline verification boundary. It performs no network request, acquisition, account creation, payment, terms acceptance, or publisher contact. The fixed import root is `data/imports/kentucky-business-entity-bulk/packages/`; each package contains exactly `selection.json` and `companies.txt`. Officer files are explicitly forbidden.

The package declares one temporal scope and whether the delivered tab-delimited file contains a header. The official documentation does not establish header presence, so the parser never guesses: a declared header must exactly equal the official ordered 42-field roster, while a declared headerless file treats every line as data. Every field is parsed as text to preserve leading zeros. The manifest pins filename, byte size, SHA-256, and row count. The validator enforces path containment, regular singly-linked files, closed inventory, read-time identity stability, byte/line/row ceilings, and cooperative cancellation.

The organization key is the composite `(ID, comptype, compseq)` and `recordnumber` is retained independently. Neither is claimed permanent or non-reused. The parser enforces the published widths: 7-digit ID, 2-digit company type, 5-digit company sequence, 7-digit record number, 3-character Type, and 2-character state/address codes. Native `Type`, `Status`, `Standing`, and relevant date literals are preserved without translating them into operation claims. Dates must be real calendar dates in exact `mm/dd/yyyy` form; status is limited to `A`, `D`, or `I`; standing is blank or `G`, `B`, or `X` only for company types `06` and `09`. Country is blank or two characters, and source ZIP text is bounded at ten characters. Blank `profit` stays `null`; nonblank profit is `P` or `N` only for company type `09` and is never inferred.

Privacy minimization happens at normalization. Registered-agent fields 10–17, residence date, and applicant/title fields are never emitted. The obsolete finance/share fields `parpre`, `parcomno`, `parcom`, and `parpreno` are discarded, as are `numofcr`, `numofshr`, and `mangnum`, because no use is justified. Raw input is classified `person-bearing-internal`; normalized output is `local-review-only`. Principal-office address is administrative evidence only and may be residential or outside Kentucky. Valid ZIP5 and ZIP+4 values are separated; blank values remain null, while malformed but safe text is retained as `postal_raw` with `postal_parse_status: unresolved-format` and no parsed ZIP claim.

This contract writes no artifact, release, admission, enrollment, or pointer. Source authenticity, statewide completeness, current operation, physical-site identity, redistribution authorization, national admission, production enrollment, identifier permanence/non-reuse, and pointer-change claims are all false. Tests use synthetic rows only; no Kentucky business record is included.

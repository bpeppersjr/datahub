# USDA FSIS source-defined active establishment coverage

This retained-only governed aggregate replays the exact pinned USDA FSIS active Meat, Poultry and Egg Product Inspection Directory release dated `2026-08-24`, its matching demographic supplement, and pinned Census ZIP/ZCTA geography. It makes no network requests and is nonadditive to generic business totals.

The source-defined cohort contains 7,237 accepted active-directory establishment records across all 51 states/DC and five territories. The records have 4,367 positive ZIP5 values within a 37,859-row governed ZIP union. ZIP5 and ZIP4 remain separate, and Census ZCTA membership is statistical geography rather than current USPS validity.

Directory membership is source-specific regulatory evidence. It does not represent all food businesses, all inspected businesses, unique legal businesses, current operation beyond the source directory assertion, physical public access, current hours, ownership, or nationwide completeness.

Only aggregates are published. Names, other names, addresses, phones, coordinates, geometry, establishment identifiers, record identifiers, DUNS values, and raw records are prohibited.

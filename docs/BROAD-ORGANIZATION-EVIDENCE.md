# Broad organization evidence projection

The completion matrix and state-access report share one offline projection for the retained broad organization layers in Colorado, Connecticut, Delaware, Florida, Iowa, New York, Oregon, and Pennsylvania. The projection is derived from the verified current coverage source rows and each state's pinned source-policy bytes. It does not query a publisher, refresh data, change a pointer, or authorize acquisition.

For each state the projection records the source and release identifiers, publisher reference date and temporal review result, source-specific legal-status semantics, ZIP contribution and address counts, and the source-policy ID, version, SHA-256, review date, field-export rules, and redistribution limitation. General operating status and complete-business coverage remain false.

These broad source rows are organization/ZIP projections and do not carry source-level location-profile geocode denominators. Their geocode status is therefore `unmeasured-at-source-level`, with null assigned, eligible, and percentage values. The reports must never substitute the jurisdiction-wide geocode rate, which includes unrelated retained sources.

The authorization block is evidence-only: acquisition is false, acquisition authority is not inferred, and production pointer changes are false. Source evidence already retained in production remains distinguishable from permission to acquire or publish anything new.
